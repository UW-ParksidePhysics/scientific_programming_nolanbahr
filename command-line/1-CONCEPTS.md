# Concepts
- **Prompt**: Entered commands at the terminal prompt.
- **Directory**: Navigated between directories using 'cd'.
- **Home Directory**: Returned to the home directory using 'cd ~'.
- **Argument**: Passed directory names as arguments to commands.
- **Metacharacters**: Used '~' to represent the home directory.
- **Text Editor**: Used Deepnote to create and edit files.
